## Description du Bot

Otter est un bot discord qui a pour but d'aider a la gestion de serveur( modération , utilitaire ) et faire de la musique .

## Technologies

Environnment de l'application : Visual Studio Code
Developper sous Gitlab
Langage : Discord.js

## Pas à pas d'installation
:warning: Le bot n'est pas encore fonctionnel sur d'autres serveur :warning: 
Lien d'invitation discord : [Otter](https://discord.com/oauth2/Otter)

## Fonctionnalités

- Joue de la musique via youtube 
- Permet de bannir/expulser un membre d'un serveur 
- Obtenir des informations sur le serveur ou les membres
- Crée un système de cooldown sur les salons 
- Permet d'ajouter/retirer des roles aux membres
